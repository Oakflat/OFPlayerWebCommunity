# Open Source Scope

This community branch is prepared as a public baseline for the browser player, local music tools, tutorials, and reusable UI.

## Included

- `src/app/**`, `src/components/**`, `src/composables/**`, `src/models/**`, `src/services/**`, and `src/tools/**`
- browser local-first playback and catalog state
- docs, tutorials, theming references, and utility pages
- reusable UI packages under `packages/**`

## Removed From This Branch

- product landing, download, and policy pages
- prerender assets and private release-ticket integrations
- sponsorship and promotion components
- upgrade dialogs and account-tier surfaces

## Before Public GitHub Release

- choose and add the final license
- confirm branding and bundled assets are acceptable for public distribution
- keep private roadmap work outside this repository
