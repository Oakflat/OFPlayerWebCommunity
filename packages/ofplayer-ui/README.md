# @ofplayer/ui

A small frontend extraction package for OFPlayer's reusable interface primitives.

## Included Today

- `UiDialogModal`
- `UiMenuDropdown`
- shared design tokens for the current calm, premium visual language

## Not Included Yet

- playback engine behavior
- queue and library state management
- local import and metadata services
- IndexedDB persistence

## Release Note

This package is intentionally marked `UNLICENSED` until the public release terms are decided.
