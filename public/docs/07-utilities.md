# Utilities

The community branch keeps generic local-first helpers and removes private release helpers.

## Useful Helpers

| File | Purpose |
| --- | --- |
| `src/utils/lrcParser.js` | LRC parsing and validation support |
| `src/utils/zipBuilder.js` | Local export ZIP generation |
| `src/utils/colorExtractor.js` | Artwork color extraction |
| `src/utils/versionedStorage.js` | Build-aware local storage reads |
| `src/composables/useAudioPlayer.js` | Browser playback control |
| `src/composables/usePlayerColor.js` | Player color derivation and CSS variable updates |
