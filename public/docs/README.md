# 网页社区版使用指南

第一次打开网页播放器，先[导入一首本地歌曲](./user/getting-started.md)，再试[播放、暂停和切歌](./user/playback.md)。曲库保存在当前浏览器。要整理收藏，读[曲库和歌单](./user/libraries-playlists.md)。

- 想换颜色和外观，打开[主题指南](./user/themes.md)。
- 想改播放器界面，先读[项目结构](./02-architecture.md)和[界面组件](./03-components.md)。
- 想扩展功能，查[共用工具](./07-utilities.md)和[二次开发](./09-secondary-development.md)。
