# 快速上手

> [!TIP]
> OFPlayer 完全在你的浏览器中运行，无需安装任何软件，音乐文件始终保留在你的设备上。

## 欢迎使用 OFPlayer

OFPlayer 是一款本地优先的网页音乐播放器。你只需打开浏览器，导入本地音频文件，即可开始聆听——无需注册账号，无需联网，音乐完全属于你自己。

## 第一步：打开播放器

在浏览器中访问播放器页面，你会看到一个居中的播放器界面，分为三个区域：

- **左侧**：导航栏，包含库、播放列表和设置入口
- **中间**：当前播放列表的曲目列表
- **右侧**：当前曲目的详情信息
- **底部**：全局播放控制条

## 第二步：导入你的第一首歌

1. 点击左侧导航栏底部的 **导入** 按钮（↑ 图标）
2. 在弹出的文件选择框中，选择你的音频文件
3. 支持的格式：MP3、FLAC、WAV、OGG、M4A、AAC
4. 文件会自动进入当前活跃的库，并添加到默认播放列表

> [!NOTE]
> 你可以一次选择多个文件，OFPlayer 会批量读取元数据（曲名、艺术家、专辑、封面等）。

## 第三步：开始播放

- 在曲目列表中**双击**任意一首歌，即可立即播放
- 底部控制条会显示当前播放进度和基本控制按钮
- 右侧面板会展示当前曲目的封面、标题和艺术家信息

## 界面概览

| 区域 | 功能 |
|------|------|
| 左侧导航 | 切换库和播放列表，查看智能视图（最近播放、收藏等） |
| 中间内容 | 当前播放列表的曲目表格，支持排序和搜索 |
| 右侧详情 | 当前曲目封面、信息和歌词（如有） |
| 底部控制 | 播放/暂停、上下首、进度条、音量控制 |
