# 导入音乐

OFPlayer 支持从你的本地设备导入音频文件。所有文件在导入后仅保存在你的浏览器存储中，不会上传到任何服务器。

## 支持的文件格式

| 格式 | 说明 |
|------|------|
| **MP3** | 最通用的有损格式，兼容性最好 |
| **FLAC** | 无损压缩，音质最高，文件较大 |
| **WAV** | 无损未压缩，文件最大 |
| **OGG** | 开源有损格式 |
| **M4A / AAC** | Apple 常用格式，有损 |

## 导入文件

### 方法一：点击导入按钮

1. 找到左侧导航栏底部的上传图标（↑）
2. 点击后弹出系统文件选择框
3. 选择一个或多个音频文件（按住 Ctrl 或 Cmd 可多选）
4. 点击「打开」确认

### 方法二：拖拽导入

直接将音频文件从文件管理器拖拽到播放器界面，文件会自动被识别并导入。

> [!TIP]
> 如果你有大量音乐文件，建议分批导入，每批 200 首以内，以保证流畅的导入体验。

## 元数据读取

导入时，OFPlayer 会自动读取文件中的 **ID3 标签**（元数据），包括：

- 曲名（Title）
- 艺术家（Artist）
- 专辑（Album）
- 专辑封面（Artwork）
- 年份、曲目编号、流派等

> [!NOTE]
> 如果文件没有嵌入元数据，OFPlayer 会以文件名作为曲名，艺术家和专辑字段留空。

## 导入后的位置

导入的文件会自动：

1. 进入**当前活跃的库**（Library）
2. 出现在该库的**默认播放列表**中

你可以之后将曲目手动添加到其他播放列表。

## 常见问题

**Q：导入的音乐会占用多少空间？**  
OFPlayer 使用浏览器的 IndexedDB 存储音频文件。实际占用大小取决于你的文件总量和浏览器的存储限制（通常为设备可用空间的 60%）。

**Q：重启浏览器后音乐还在吗？**  
是的。IndexedDB 是持久性存储，数据会一直保留，除非你手动清除浏览器数据，或在设置中删除库。

**Q：支持直接选择整个文件夹吗？**  
目前文件选择框支持点击选择多个文件，暂不支持原生文件夹递归导入（受浏览器 API 限制）。

**Q：文件损坏或格式不支持怎么办？**  
不支持的文件会在导入完成后显示错误提示，其余文件仍会正常导入。
