# 快捷键

使用键盘快捷键可以大幅提升操作效率。

## 全局快捷键

这些快捷键在播放器主界面任何位置均可使用：

| 快捷键 | 功能 |
|--------|------|
| `Space` | 播放 / 暂停 |
| `→` 右箭头 | 快进 5 秒 |
| `←` 左箭头 | 快退 5 秒 |

> [!NOTE]
> 当焦点在文本输入框（如搜索栏）内时，空格键等快捷键不会触发播放控制。

## 沉浸式视图快捷键

进入沉浸式播放视图（全屏模式）后可使用：

| 快捷键 | 功能 |
|--------|------|
| `Esc` | 退出沉浸式视图 |
| `Space` | 播放 / 暂停 |
| `→` 右箭头 | 快进 5 秒 |
| `←` 左箭头 | 快退 5 秒 |

## 设置面板快捷键

| 快捷键 | 功能 |
|--------|------|
| `Esc` | 关闭设置面板 |

## 提示

- 大多数按钮都支持 `Tab` 键导航，`Enter` 键确认，符合无障碍标准
- 在曲目列表中可使用 ↑ / ↓ 方向键浏览，`Enter` 键播放选中曲目
