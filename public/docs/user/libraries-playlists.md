# 库与播放列表

OFPlayer 使用「库（Library）」和「播放列表（Playlist）」的两级结构来组织你的音乐。

## 概念说明

### 库（Library）

库是最顶层的容器，类似于「音乐文件夹」的概念。你可以创建多个库，例如：

- 个人收藏
- 工作背景音乐
- 古典音乐专区

每个库拥有独立的曲目集合和播放列表。

> [!NOTE]
> 每个库在创建时会自动生成一个「默认播放列表」。导入的文件会先进入库，然后自动出现在该库的默认播放列表中。

### 播放列表（Playlist）

播放列表属于某个特定的库。一首曲目可以同时出现在同一个库的多个播放列表中。

### 智能视图

智能视图不属于任何库，它们是系统根据特定规则自动生成的视图：

| 视图 | 说明 |
|------|------|
| 最近播放 | 按播放时间排序，显示最近听过的曲目 |
| 收藏 | 所有标记为收藏的曲目 |
| 当前队列 | 正在播放的队列顺序 |

## 管理库

### 创建新库

1. 在左侧导航栏找到库列表区域
2. 点击「添加库」按钮（+ 图标）
3. 输入库名称，确认创建

### 切换活跃库

点击左侧导航栏中任意库的名称，即可将其切换为当前活跃库。切换后，新导入的音乐会进入该库。

### 删除库

> [!CAUTION]
> 删除库会同时删除该库中的所有曲目和播放列表，此操作无法撤销。

右键点击库名称，选择「删除库」，在确认弹窗中点击「确认删除」。

## 管理播放列表

### 创建播放列表

1. 在左侧导航栏选择目标库
2. 点击播放列表区域旁的「+」按钮
3. 输入播放列表名称，确认创建

### 向播放列表添加曲目

在曲目列表中，右键点击任意曲目 → 选择「添加到播放列表」→ 选择目标播放列表。

### 在播放列表内排序

播放列表支持以下排序方式（点击中间内容区的列表头切换）：

- 按曲名排序
- 按艺术家排序
- 按专辑排序
- 按时长排序
- 按添加时间排序

### 删除播放列表

右键点击播放列表名称 → 选择「删除播放列表」。

> [!NOTE]
> 删除播放列表只会移除播放列表本身，曲目文件仍保留在库中，不会被删除。

## 从播放列表中移除曲目

右键点击曲目 → 选择「从播放列表中移除」。这只会移除曲目与该播放列表的关联，不会删除文件。
