# 歌词

OFPlayer 支持 LRC 格式的歌词文件，可以实现逐行同步滚动显示。

## 歌词面板

在播放器右侧面板的底部，找到歌词图标，点击即可展开歌词面板。

- 歌词会随播放进度**自动滚动**，当前行高亮显示
- 点击任意歌词行，可以**跳转**到该时间点

> [!TIP]
> 如果当前曲目没有歌词，歌词面板会显示「暂无歌词」提示，你可以手动为其绑定 LRC 文件。

## LRC 文件格式

OFPlayer 使用标准的 **LRC（Lyric）** 格式。LRC 是一种纯文本文件，后缀为 `.lrc`，结构如下：

```
[ti:歌曲标题]
[ar:艺术家]
[al:专辑]
[00:00.00] 第一行歌词
[00:05.50] 第二行歌词
[01:20.30] 副歌部分
```

时间戳格式为 `[分:秒.毫秒]`。

## 加载歌词文件

### 手动加载

1. 在曲目右键菜单中选择「加载歌词」
2. 选择与当前曲目对应的 `.lrc` 文件
3. 歌词立即加载并开始同步显示

### 自动匹配（同名文件）

如果 `.lrc` 文件与音频文件放在同一目录，且文件名相同（仅后缀不同），导入时会尝试自动匹配。

例如：
```
song.mp3
song.lrc  ← 自动匹配
```

> [!NOTE]
> 自动匹配需要在同一批次导入时同时选择音频文件和 LRC 文件。

## 歌词存储

加载过的歌词会被保存在浏览器本地存储中，下次打开 OFPlayer 时会自动恢复，无需重新加载。

## 沉浸式视图中的歌词

进入**沉浸式播放视图**时，歌词会以更大的字体显示在界面中央，配合动态背景提供更好的沉浸体验。
