# 播放控制

掌握 OFPlayer 的全部播放功能，让聆听体验更流畅。

## 底部控制条

底部控制条是播放器的主控区域，包含以下功能：

### 播放控制

| 按钮 | 功能 |
|------|------|
| ⏮ | 上一首 / 跳回曲目开头 |
| ⏸ / ▶ | 暂停 / 播放 |
| ⏭ | 下一首 |

> [!TIP]
> 在曲目播放超过 3 秒后，点击「上一首」会先跳回当前曲目的开头，再次点击才会切换到上一首。

### 进度条

- **点击**进度条上的任意位置，跳转到对应时间点
- **拖拽**进度条滑块，精确定位播放位置
- 进度条左侧显示当前时间，右侧显示总时长

### 音量控制

- 点击音量图标可以快速静音 / 取消静音
- 拖拽音量滑块调节音量大小（0%–100%）
- 音量设置会在页面刷新后自动恢复

## 播放模式

OFPlayer 支持以下播放模式，点击控制条中的循环/随机图标切换：

| 模式 | 图标 | 说明 |
|------|------|------|
| 顺序播放 | → | 按列表顺序播放，播完停止 |
| 列表循环 | 🔁 | 播完列表后从头循环 |
| 单曲循环 | 🔂 | 反复播放当前曲目 |
| 随机播放 | 🔀 | 从当前列表随机选取下一首 |

## 当前队列

点击底部控制条的队列图标（☰），可以查看**当前播放队列**：

- 队列显示即将播放的曲目顺序
- 可以拖拽队列中的曲目调整播放顺序
- 点击队列中的曲目立即播放

> [!NOTE]
> 「当前队列」是一个临时视图，它反映的是当前播放列表的顺序（包含随机播放时的乱序状态）。

## 沉浸式播放视图

点击右侧面板的封面图片或专辑艺术，可以进入**沉浸式播放视图**：

- 全屏展示当前曲目封面和渐变背景（颜色自动从封面中提取）
- 显示更大的控制按钮
- 支持键盘快捷键控制（空格键暂停/播放）
- 按 `Esc` 键或点击关闭按钮退出

## 收藏曲目

在曲目列表中或右侧面板，点击心形图标 ♡ 即可收藏当前曲目。收藏的曲目可以在左侧「收藏」智能视图中快速访问。
