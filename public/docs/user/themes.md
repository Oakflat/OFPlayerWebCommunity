# 主题与设置

OFPlayer 内置多套精心设计的主题，并提供多项个性化设置选项。

## 切换主题

点击左侧导航栏底部的**设置**图标，进入设置面板，在「外观」部分可以选择主题。

### 可用主题

#### Mist（默认）

玻璃质感主题，采用毛玻璃效果（backdrop-filter blur），背景半透明，层次感强。适合搭配各类壁纸使用，是大多数用户的首选。

#### Paper

温暖哑光主题，模拟纸质质感，无反光、无过强的阴影，边框柔和，适合长时间使用，减少视觉疲劳。

#### Material

遵循 Material Design 规范的主题，层次清晰，阴影和交互反馈更明确，适合习惯 Android 设计语言的用户。

> [!TIP]
> 主题偏好会自动保存在本地，刷新页面或重新打开浏览器后依然生效。

## 语言设置

OFPlayer 支持以下界面语言：

- 简体中文（默认）
- English

在设置面板中切换「界面语言」，页面会立即更新，无需刷新。

## 颜色方案

每套主题都内置了亮色和暗色两种颜色方案，可在设置中独立切换，也可跟随系统偏好（「跟随系统」选项）。

## 播放设置

在设置面板的「播放」部分，可以调整以下选项：

| 选项 | 说明 |
|------|------|
| 默认播放模式 | 设置打开播放器时的初始播放模式 |
| 音量记忆 | 是否记忆上次关闭时的音量 |
| 连续播放 | 播放列表播完后是否自动停止 |

## 数据管理

在设置面板的「数据」部分，可以执行以下操作：

- **导出库数据**：将所有库和播放列表信息导出为 JSON 文件（不含音频文件本体）
- **清除所有数据**：删除浏览器中存储的全部 OFPlayer 数据

> [!CAUTION]
> 「清除所有数据」操作会永久删除所有库、播放列表和存储的歌词，且**无法恢复**。音频文件本身不会被删除（它们仍在你的本地磁盘上），但 OFPlayer 中的组织信息会全部丢失。
